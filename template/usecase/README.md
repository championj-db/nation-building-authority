## Deploy

```bash
databricks bundle validate --target dev --var catalog=<YOUR_CATALOG>
databricks bundle deploy   --target dev --var catalog=<YOUR_CATALOG>
databricks bundle run {{usecase_name}} --target dev --var catalog=<YOUR_CATALOG>
```

Replace `<YOUR_CATALOG>` (angle brackets included) with a catalog you can write to. To avoid
repeating it, put your values in `.databricks/bundle/dev/variable-overrides.json`, which is
git-ignored.

### Variables

| Variable | Required | Purpose |
| --- | --- | --- |
| `catalog` | Yes | Catalog owning this use case's schemas, volumes and models |
| `schema` | No | Defaults to the use case name, suffixed per user in `dev` |
| `volume` | No | Landing volume for raw files |
| `warehouse_id` | For dashboards | SQL warehouse backing dashboards and SQL tasks |
| `notifications_email` | No | Defaults to the deploying user |
| `environment` | No | Environment tag, set per target |
