## Design Context

### Surface type
Databricks App (AppKit: Node + React). Two views share a top bar: the **Review queue** (summary
metrics, status tabs, filters, case table, case review drawer) and **Precision** (how many flags
held up once investigated).

### Audience
Integrity-operations investigators in an Australian public-sector agency, working a shared daily
queue on desktop browsers; team leads reading precision.

### Theme
Light by default, with the dark theme defined in the design (toggle persisted per browser).

### Brand (locked)
- Source: design/improper-payments-workbench.html (Genie Design export). Product truth: ../../PRODUCT.md.
- Palette: Lava #FF3621 (accent: tab rule, focus, markers), Navy #0B2026 ink, Oat #EEEDE9 / #F9F7F4 surfaces.
  `--lava-strong` #C42A18 for filled controls that carry text (Oat on #FF3621 is only 3.4:1).
- Typography: DM Sans (self-hosted variable font) + system monospace for ids, money and scores.
- Token names avoid AppKit UI's shadcn variables (--accent, --muted, --border): --lava, --fg-muted, --line.
- Icons: lucide-react, 1.75 stroke. No Unicode glyphs as icons.
- Voice: plain Australian Government register. Every surface carries the synthetic-data notice;
  scores are indicators, not findings.
