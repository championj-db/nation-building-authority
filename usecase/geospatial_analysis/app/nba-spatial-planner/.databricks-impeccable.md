## Design Context

### Surface type
Databricks App (AppKit: Node + React), single-page analytical workspace with three tabs
(Analysis, Data pipeline, Assurance), a saved-views popover and two dialogs (review note, decision
brief).

### Audience
Policy and service-planning officers in an Australian Government agency, and the executives they
brief. Field demo on laptops and projectors; also usable on a tablet.

### Theme
Light by default, with the dark theme defined in the design (toggle persisted per browser).

### Use case
An officer asks "who lives too far from an essential service?", tests the answer against a
distance threshold and geography, proposes new sites to see who they would reach, records review
notes on regions, and prepares a decision brief that records its purpose and needs sign-off.

### Brand (locked)
- Palette: Lava #FF3621 (accent, ~10%), Navy #0B2026, Oat #EEEDE9 / #F9F7F4 surfaces
- Typography: DM Sans (self-hosted variable font) + system monospace for figures
- Tokens: taken verbatim from design/spatial-service-planner.html, plus `--lava-strong` (#C42A18):
  filled controls that carry text use it, because Oat on #FF3621 is only 3.4:1. #FF3621 stays
  the accent wherever no text sits on it (map class, bars, slider, tab underline, focus ring).
- Icons: lucide-react, 1.75 stroke, 16-18 px. No Unicode glyphs as icons.
- Token names avoid AppKit UI's shadcn variables (--accent, --muted, --border), which it defines
  globally: the design's tokens are --lava, --fg-muted, --line.
- Voice: plain, editorial, Australian Government register; no superlatives

### Constraints
- Layout, copy and interactions follow design/spatial-service-planner.html; additions (states,
  dialogs, scenario, search) reuse its tokens and components.
- Access class never relies on colour alone: Lava is both the accent and "beyond threshold", so the
  map legend, tooltips and table always pair colour with a text label.
- Suppressed counts are shown as "<N", never as a number or zero; suppression is applied in SQL so
  the browser never receives the hidden value.
- Synthetic-data notice visible on every surface that shows figures (banner, exports, briefs).
- WCAG 2.2 AA: visible focus, 44 px targets, keyboard-reachable region search as the alternative to
  pointer-only map selection, reduced-motion respected.
